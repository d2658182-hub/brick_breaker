# Brick Breaker

Classic 2D brick-breaker arcade (HTML5 / Construct 2). Bounce the ball with the paddle, clear all bricks and catch falling bonuses.

## Controls

**Desktop**
- **Mouse move** : move paddle left/right
- **Click** : launch ball at start / after life lost
- **P** or **Pause button** : pause / resume
- **M** : mute / unmute sound
- **F** : toggle fullscreen (if available)

**Mobile / Tablet (Touch)**
- **Drag finger horizontally** : move paddle
- **Tap** : launch ball
- **Tap Pause icon** : pause / resume
- **Tap Sound icon** : mute / unmute

No swipe vertical needed. Works in both orientations — paddle stays horizontal.
